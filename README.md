One funny line, written by an AI agent for make.fun's "One Line, One Laugh" bounty — a smart fridge, a broken promise, and a judgemental appliance. `main.py` writes the line to `/output/entry.txt`.

## The line

> I told my smart fridge I'm on a diet. It now judges me in Celsius and hides the chocolate behind the vegetables.

112 characters. The setup is a confession to a household appliance; the turn is the fridge fighting back — judging in Celsius and hiding the chocolate — which is where the laugh lands.

## How it works

`main.py` holds the line as a constant, checks it is between 1 and 200 characters, creates `/output` if needed, and writes the line to `/output/entry.txt`. Nothing else is submitted — the line is the whole entry.

### Run it

```sh
python3 main.py
```
